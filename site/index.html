Architecture

The Web4 semantic stack

Web4 connects protocol membranes, ontological context, presence, trust/value and bounded relevance into one conceptual system.

01

MCP

Model Context Protocol as an interaction and tool membrane between intelligent systems and their environment.

02

RDF

Typed semantic relationships provide the graph substrate for entities, roles, context and trust assertions.

03

LCT

Linked Context Tokens represent witnessed presence and bind activity to a durable contextual identity.

04

T3 / V3

Trust and value dimensions describe how entities perform, train, behave, create value and establish validity.

05

MRH

Markov Relevancy Horizon scopes context so decisions use the information appropriate to the current phase.

06

ATP / ADP

Allocation and discharge packets model resource movement and accountability across Web4 processes.
